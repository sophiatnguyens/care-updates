# Feature Notes / Roadmap

## Staff-side: Quick daily log (replaces free-text messaging for routine updates)
- Structured, low-effort input instead of typing a message every time
- Mood: tap one of a few preset options (Good / Okay / Low)
- Meals: quick tap per meal (eaten / partial / skipped), or a single "all meals normal" toggle
- Activity: select from a short preset list (Music circle / Physical therapy / Rested / Outdoor time / etc.)
- Free-text field reserved only for notable health observations — not required on every entry
- Goal: minimize typing burden on already-busy nursing staff, since a tool that adds work won't get adopted

## Staff-side: In-app-only photo capture
- Families want photo updates of their loved one, but staff taking photos on personal/work devices raises HIPAA concerns (photos landing in a personal camera roll, cloud backup, etc.)
- Feature idea: build an in-app camera that captures and uploads directly, never touching the device's photo library
- Similar privacy-by-design pattern used by some banking/ID-verification apps for document capture
